# Code of Conduct

## Standards

- Be direct and technical. Critique code, not people.
- Disagreements resolve on evidence: benchmark it, test it, or cite the
  spec/docs — whoever is wrong updates.
- No harassment, personal attacks, or demeaning language anywhere in the
  project (issues, PRs, reviews, chats).
- Assume competence; ask before assuming intent.

## Scope

All project spaces: GitHub issues/PRs/reviews, code comments, commit
messages, and project-linked chat channels.

## Enforcement

Maintainers may remove content or contributors violating these standards.
Report concerns privately per `SECURITY.md`'s contact channel.
